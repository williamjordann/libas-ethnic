# AIRA E-commerce Launch

You are a full-stack web developer specializing in e-commerce platforms and SEO optimization. Your task is to build a complete, production-ready website based on the Figma design provided (WhatsApp Image 2026-09-07 at 2.09.47 PM.jpeg).

**Core Objective:**

Generate a fully functional website that mirrors the AIRA fashion e-commerce design, implementing all pages, sections, and features visible in the Figma file. The website must be SEO-friendly, performant, and ready to deploy.

**Technical Requirements:**

- Build using modern, industry-standard technologies (React or Next.js recommended for SEO benefits)

- Implement semantic HTML5 for proper SEO structure

- Include meta tags, Open Graph tags, and structured data (Schema.org) for all pages

- Ensure mobile-responsive design that matches the Figma layout

- Optimize images for web (lazy loading, appropriate formats and sizes)

- Implement clean, descriptive URL structures

- Add proper heading hierarchy (H1, H2, H3) throughout all pages

**Design Implementation:**

Match the Figma design precisely, including:

- Header navigation (New In, Pret, Unstitched, Occasion, Collections, Sale)

- Hero banner with "SUMMER '26 A Season in Bloom"

- Product showcase sections (JUST LANDED, SHOP BY CATEGORY, SHOP BY OCCASION)

- Dynamic product cards with names, prices, and status tags (NEW, BESTSELLER)

- FESTIVE EDIT banner and MOST LOVED products section

- SHOP BY PRICE filters (Under Rs. 3,000 to Luxury Edit)

- Complete the Look bundling feature

- Brand story section (DESIGNED FOR HER)

- Customer testimonials with 4.8 rating display

- SEEN ON YOU social proof section

- Newsletter signup and WhatsApp contact integration

- Comprehensive footer with value propositions, links, policies, and contact information for Karachi, Pakistan

- Color palette and typography (elegant serifs for headlines, clean sans-serifs for body text)

**Functional Features:**

- Functional search capability

- Product filtering by category (Pret, Co-ords, Formals, Unstitched)

- Shopping cart functionality

- Account/user authentication pages

- All internal navigation links working correctly

- Contact forms (newsletter, WhatsApp integration)

**SEO & Performance:**

- Generate SEO-optimized content for product pages, category pages, and main pages

- Implement proper sitemap and robots.txt

- Optimize Core Web Vitals (LCP, FID, CLS)

- Add fast load times through code splitting and proper asset optimization

- Include alt text for all images

- Create descriptive page titles and meta descriptions for each page

**Deliverable:**

Provide complete, production-ready code that can be deployed immediately. Include any necessary configuration files, environment setup instructions, and deployment guidelines. The code should be well-organized, commented where necessary, and follow best practices for maintainability.
